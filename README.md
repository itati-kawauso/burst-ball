# Burst Chamber (3秒爆発空中ターゲットパズル)

3秒ごとに猛烈に跳ね回る玉を陣地（ボックス）で受け止め、ピストン打ち上げで空中のスコアサークルへ誘導する落ち物アクション物理パズルゲームです。

---

## 🎮 ゲームの特徴・ルール

1. **3秒爆発サイクル**: 天井から落ちてくる玉はそれぞれ個別に3秒周期で推進爆発を起こします。
2. **空中ターゲットサークル**: コア＆サブサークルは空中にランダム配置され、**「下から打ち上げられた玉」にのみ反応**してスコアになります。
3. **落下ライフ制**: 陣地から外にこぼれた玉が画面下へ落下するとライフが1減少。ライフが0になるとゲームオーバー。スタート画面で初期ライフ（3〜30）を自由に設定可能です。
4. **天井危険ライン**: 陣地から玉が溢れ、天井の警告ラインに接触・滞留すると危険度が上昇し、100%に達するとゲームオーバーになります。
5. **KINETIC LAUNCH PISTON**: `W` キーまたは `↑` キーで陣地底面のピストンを作動させ、溜まった玉を一気に空中へ射出できます。
6. **BURST FREEZE (爆発一斉停止)**: `Space` キーで発動。10秒のリチャージを消費して3.5秒間全玉の爆発を停止＆タイマーを3.0秒にリセットします。

### 操作方法

| キー / 操作 | 動作 |
|---|---|
| `A` / `D` または マウスドラッグ | 陣地（箱）の左右移動 |
| `Q` / `E` | 陣地（箱）の傾き |
| `W` / `↑` | ピストン打ち上げ（玉を上空へ射出） |
| `Space` | BURST FREEZE（全玉の爆発停止＆タイマーリセット） |
| `Esc` / `P` | ポーズ / 再開 |

## 🚀 GitHub Pages への公開手順

本リポジトリは完全なクライアントサイド（HTML5 Canvas + React + Web Audio API）で動作し、外部サーバーやデータベースなしで静的サイトとしてGitHub Pagesに公開できます。

### 方法 1: GitHub Actions による自動公開（推奨）

リポジトリ内に `.github/workflows/deploy.yml` が用意されているため、自動的にデプロイされます。

1. 本プロジェクトを GitHub リポジトリ（例: `username/burst-chamber`）に push します。
2. GitHub リポジトリの **Settings** > **Pages** を開きます。
3. **Build and deployment** の **Source** で **「GitHub Actions」** を選択します。
4. `main` ブランチに push すると自動でビルド＆デプロイが走り、`https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます。

### 方法 2: 手動ビルドによる静的ファイル公開

ローカルでビルドして `dist` フォルダを公開する場合：

```bash
# 依存パッケージのインストール
npm install

# 本番用静的ファイルのビルド
npm run build
```

ビルド後に出力される `dist` フォルダ内のファイル一式（`index.html`、`assets/`）を、GitHub リポジトリの `gh-pages` ブランチのルートに push してください。
`vite.config.ts` にて `base: './'` が設定されているため、サブディレクトリでも相対パスで正常にリソースが読み込まれます。
